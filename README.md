## ASCII wallpapers

Open `index.html` in any browser (works on phones) to pick one of 12 live ASCII wallpapers. The scenes come from
[0toshigami/claude-desktop-themes](https://github.com/0toshigami/claude-desktop-themes) (MIT, see
`vendor/claude-desktop-themes/LICENSE`). After editing `web-engine.js` or the vendored files, run `node tools/build.mjs`.
